# Security Policy

This repository contains the published AURA technical specification, reference
materials and separately labelled proposals. It is not a production service.

## Report a security concern

Email the maintainer, Romain Benabdelkader, at
[romain_ee@yahoo.fr](mailto:romain_ee@yahoo.fr), with the subject
`AURA security report`. Use this private contact for suspected weaknesses in
the specification, cryptographic usage, example code or test tooling.
Do not put exploit details or private data in a public issue.

Include the affected repository, commit or release, the expected and observed
behavior, and a minimal reproduction using test data. Do not send private keys,
passwords, personal files or production records. This is an ordinary email
channel, not a promise of end-to-end encryption.

The maintainer will coordinate verification and any disclosure with the reporter.
There is no guaranteed response time or continuous security monitoring.
Public issues remain appropriate for non-sensitive documentation questions.
