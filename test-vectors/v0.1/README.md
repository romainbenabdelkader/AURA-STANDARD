# Historical v0.1 vectors — not current conformance tests

The v0.1 draft is superseded. These exact signed files are preserved for
historical reproduction with the original v0.1 rules and key representation.
The `VALID` expectation in [the historical test descriptions](../../TEST_VECTORS.md#legacy-v01-vectors)
does not mean that the current v1.0/v1.1 AURA-VERIFIER accepts this format.
The current verifier rejects unsupported versions.

Use [the neutral v1.1 package](../../examples/quickstart-v1.1/README.md)
for current verification. Do not edit, relabel, re-sign or silently convert
these historical files. A current verifier's unsupported-version result is
not evidence that the original historical signature was forged.

This folder uses `origin_proof_version: "0.1"`. It is not the Python demo's
format or AUTHENTICA's `aura_version: "0.1-pilot"` format.
